## Decision

Stop scaling headline E2 until the paper-to-code contract is corrected. Keep

problem, but the harness must itself be measured with non-leaking, verifier-

## Critical findings

1. E1 reward parsing used `int(text)`, so decimal rewards such as `1.0` were
   recorded as missing.
2. `civ6-adjacency-optimizer` is a separate upstream verifier inconsistency:
   reward `1.000` was emitted although captured pytest output had two failures.
3. Scripted prompts exposed YAML frontmatter, including `required_skills` or
   distractor metadata on affected tasks.
4. `radar-vital-signs` copied the curated bundle into multiple provider-native
   paths in the Docker image, contaminating the nominal C0 arm.
5. Scripted C1 is text-only, capped at 24k characters, and prompt-injected; it
   is not the paper's complete native bundle interaction.
6. Default verifier-feedback repair leaked withheld verifier output into a
   second attempt. Evaluation must use zero repair.
7. The previous `seed=1` label was false: the provider CLI had no controlled
   seed and there was only one trial per cell.
8. The curated task bundle had been mislabeled as empirical `S*(q)`. Empirical
   oracle membership must be estimated per task/model/backend/harness/tau.
9. The index counted `licenses/` helpers without `SKILL.md` as a Skill.
10. Lifecycle admission used `all([])`, allowing empty evidence to adopt, and
    target verifier failures were rejected rather than routed to repair.
11. More Skills metrics used selected/self-reported skill IDs instead of actual
    body invocation evidence; exact conditional-rate decomposition was absent.
12. Harness hooks/evolution are scaffolds: no hook-specific mutation contract,
    and the evolution gate trusts external deltas without executing smoke and
    paired regression evidence.
13. A CLI workspace nested inside the repository can inherit parent project
    instructions or user customizations. The first agentic preflight also
    exposed a non-interactive Bash approval failure under `acceptEdits`.

## Corrections implemented

- Parse verifier rewards as finite floats in `[0,1]`; preserve partial reward.
- Pre-create `/logs/verifier` and separate reward failure, partial reward,
  timeout, and verifier infrastructure status.
- Respect task-level build/agent/oracle/verifier budgets and Docker CPU,
  memory, and no-network declarations.
- Strip task frontmatter from model-visible instructions.
- Build model-run task images from a neutral context whose root `skills/` is
  empty; C1 skills are supplied separately by the harness.
- Set scripted evaluation repair default to zero; label nonzero repair as
  adaptation-only `scripted_repair`.
- Record `B_cli`, user-owned account auth, no credential forwarding, trial
  index, unavailable provider seed control, prompt hash, and skill truncation.
- Preserve raw readiness output and add a non-destructive reclassifier.
- Rename task bundle mapping to `curated_skill_variants`; exclude helpers that
  lack `SKILL.md`. Current index: 209 variants, 195 names.
- Compare the vendored task tree against the actual pinned upstream Git object
  tree: all 2,160 regular blobs match. One upstream gitlink is an explicit empty
  placeholder rather than silently being called a materialized file tree.
- Regenerate static readiness, split, and scheduling manifests.
- Require non-empty target and regression evidence before lifecycle adoption;
  route target verifier failures to `REPAIR`.
- Add denominator-aware n/m/o invocation summaries, conditional pass rates,
  and exact `Delta_ctx + Delta_shd` decomposition with an invariant check. The
  new API requires actual invoked IDs; legacy selected-ID wrappers stay marked
  as proxies.
- Make CTA-lite reject mismatched task/backend/model/trial/harness/verifier/
  budget/workspace pairs and compute with-skill-only unexpected artifacts from
  paired workspace manifests when that evidence is present.
- Move future agentic workspaces outside the repository, load Claude setting
  source `project` only, disable unneeded tools, and pre-allow the fixed
  Bash/Edit/Read/Write tool surface under non-interactive `dontAsk` mode.
- Add per-arm immediate JSONL records and a provenance-checking three-trial
  C0/C1 aggregator.

## ONE network diagnosis and account isolation

The failed first full-batch attempts were not caused by account metadata or a
container leak. WSL had removed `/etc/resolv.conf` after restart, so Claude
Code's runtime reported `getaddrinfo ETIMEOUT` even though account auth was
still valid. A temporary full copy of `/root/.claude.json` did not repair the
call. After restoring public DNS and making the real resolver file immutable,
the setting persisted across an explicit WSL shutdown/restart.

The decisive smoke then passed with a fresh HOME containing only a symlink to
the host account credential. No host state file was copied, no API key was
introduced, and no credential or Claude configuration was mounted into Docker.
The same isolation contract is recorded per arm in the model-run summary.
