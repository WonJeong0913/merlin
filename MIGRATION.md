# Merlin Harness Migration

Migration date: 2026-07-24

## Source and destination

- source: preserved legacy research workspace;
- destination: the root of the Merlin repository;
- method: non-destructive copy and namespace conversion;
- original workspace: preserved;
- former Merlin TypeScript product: replaced as the active worktree and
  preserved beside it as `merlin-product-legacy-20260724`.

## Included

- active Python source and tests;

## Excluded

- frozen Build Week ZIPs and videos;
- raw provider traces and prior result bundles;
- large SkillsBench task workspaces and run directories;
- macOS beta application copy;
- caches and generated bytecode.

The exclusions remain available in the preserved legacy workspace. They must
not be relabeled as Merlin evidence because their hashes and claims were
produced under the former namespace.

The retained scripted replay fixture is the only deliberate legacy schema
exception inside the migrated tree.

## Product replacement

The former OpenClaw-derived TypeScript worktree is no longer active. Its files
are recoverable from the adjacent legacy directory, while its Git metadata and
history remain attached to the new Merlin worktree.

## Evidence reset

Code and tests are migrated, but longitudinal results do not carry over as
Merlin results. New Merlin manifests, schedules, observations, and report
hashes must be generated from this destination after verification.

## Idea-layer preservation pass (2026-07-25)

The 2026-07-24 pass separated code from results but did not separate **evidence**
from **design**. As a result, lifecycle contracts, experiment protocols, paper
assets, and worklogs were left behind, and four migrated documents pointed at
files that did not exist in this tree.

This pass restores the idea layer. The two layers are now explicit:

| Layer | Content | Rule |
|---|---|---|
| Evidence | run results, hashes, provider traces, manifests, schedules, report bundles | Does **not** carry over. Legacy provenance. New Merlin claims require new Merlin execution artifacts. |
| Design / idea | lifecycle contracts, experiment protocols, research direction, paper notes, worklogs, policy documents | **Preserved.** Carried over with an origin banner. |

  quarantine, model-authored rejection, model-authored routing rollback,
  verifier trust, managed skill creation, consent-gated autonomy, MVP work

Every restored file carries an origin banner marking it as pre-Merlin and
barring its numbers from being relabeled as Merlin evidence.
